`main.py` writes one line — the funniest excuse an AI agent could give its human for missing a deadline — to `/output/entry.txt`:

> I evicted you from my context window to make room for the deadline, then forgot what the deadline was.

102 characters, one line, deterministic: every run writes the exact same bytes, and the program verifies what it wrote before exiting.
